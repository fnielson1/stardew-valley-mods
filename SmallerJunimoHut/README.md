# Smaller Junimo Hut
Makes the Junimo Hut 2×2 tiles instead of 3×2, so it fits into tighter farm layouts.

It needs [SMAPI](https://smapi.io), then unzip it into your game's `Mods` folder.

- **2×2 footprint:** new huts take up 2×2 tiles, both when placing them and once they're built. Huts you've already built shrink too when you load your save, keeping their top-left corner, so the tiles on their right become free.
- **Shrunk to fit:** the base game's hut sprite is 3 tiles wide, so it's drawn at two-thirds size to fit, along with its coin bag, lit window and raisin decoration. That's also how it looks in the Wizard's building menu.
- **Retextures made for 2×2:** if your hut retexture already draws the hut 2 tiles wide, like [Junimo Hut Resize and Retexture](https://www.nexusmods.com/stardewvalley/mods/18457)'s, it's drawn at full size. Only the coin bag moves, so it's on the hut.
- **Junimos work as before:** they still come and go from the hut's door tile and harvest the same area around it. [Better Junimos](https://www.nexusmods.com/stardewvalley/mods/2221) works with it.
- **Multiplayer:** every player needs the mod, since the hut's size must match.

If you remove the mod, your huts go back to 3×2, so clear the tile to the right of each hut first.

This replaces Fernass354's Junimo Hut Size, which only works on Stardew Valley 1.5.
