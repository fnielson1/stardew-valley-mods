# No Collision Multiplayer
Lets you walk through pets, horses, Junimos, villagers, farm animals and monsters instead of getting stuck on them, and works for every player in a multiplayer game.

It needs [SMAPI](https://smapi.io), and every player who wants to walk through things needs it installed. Each player's game decides for itself what they bump into, so a character which is created on the host, like the Junimos from a Junimo Hut, is only passable for the players who have this mod.

Don't run it together with the original No Collision Mod, since they do the same job.

## Settings
Edit `config.json` in the mod's folder, or use [Generic Mod Config Menu](https://www.nexusmods.com/stardewvalley/mods/5098) in game.

| Setting | Default | What it does |
| --- | --- | --- |
| Walk through pets (`PassThroughPets`) | on | Your cat or dog. |
| Walk through horses (`PassThroughHorses`) | on | Horses. |
| Walk through Junimos (`PassThroughJunimos`) | on | Junimos, including the ones which harvest for a Junimo Hut. |
| Walk through villagers (`PassThroughVillagers`) | off | Villagers. |
| Walk through farm animals (`PassThroughFarmAnimals`) | on | Coop and barn animals. |
| Walk through monsters (`PassThroughMonsters`) | off | Monsters, which then can't hurt you. |
| Walk through everything (`PassThroughEverything`) | off | Furniture, fences, walls and everything else, like a no-clip mode. |
